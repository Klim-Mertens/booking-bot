# Barber Demo — бот онлайн-записи для Telegram и MAX

Бот записи клиентов для салона, барбершопа, студии или частного мастера.
Один движок обслуживает сразу два мессенджера: **Telegram** (с интерактивным
календарём на HTML-виджетах Bot API 10.4) и **MAX**.

> Демо-проект для портфолио. Под конкретный бизнес бот настраивается одним
> файлом `config.toml`: услуги, цены, мастера, часы работы.

## Какую задачу решает

- Администратор не тратит время на переписку «а есть ли окошко в субботу?».
- Клиент записывается за минуту в удобное время, даже ночью.
- Меньше неявок: бот сам напоминает за сутки и за 2 часа и даёт отменить запись одной кнопкой.
- Клиенты не теряются при сбоях Telegram: тот же бот работает в MAX, база общая.

## Возможности

| Клиент | Администратор |
| --- | --- |
| выбор услуги, мастера, дня и времени | уведомление о каждой новой записи и отмене |
| календарь свободного времени прямо в сообщении (Telegram) | `/today` — записи на сегодня |
| отправка номера одной кнопкой | телефон клиента по кнопке, во всплывающем окне |
| «Мои записи» и отмена | отмена записи с уведомлением клиента |
| напоминания за 24 ч и 2 ч | |

## Безопасность

Это то, чем проект отличается от типового бота «за 5 000 ₽».

- **Нет двойных записей.** Бронирование идёт в транзакции `BEGIN IMMEDIATE`
  с повторной проверкой пересечений. Есть тест на 5 одновременных нажатий:
  проходит ровно одна запись.
- **Персональные данные защищены (152-ФЗ).** Телефон хранится зашифрованным (Fernet),
  для поиска используется HMAC-хэш. Телефон сохраняется только после явного согласия,
  а прошедшие записи автоматически удаляются через заданный срок.
- **Не доверяем вводу.** `callback_data`, данные виджета и текст проверяются по белым
  спискам, а время записи сверяется с реальными свободными слотами. Подделанная кнопка
  ничего не сломает.
- **Нельзя тронуть чужое.** Чужую запись не отменить, подставив её номер (защита от IDOR).
  Админ-функции работают только для числовых ID из настроек.
- **Чужой контакт не принимается.** Если переслать карточку друга, бот попросит свой номер.
- **Защита от флуда:** ограничение частоты действий на пользователя.
- **Секреты только в переменных окружения**, `.env` в `.gitignore`. Проверка TLS-сертификатов
  не отключается. В логах нет телефонов и токенов.
- **Минимум зависимостей:** для MAX написан свой клиент на ~60 строк вместо сторонней
  библиотеки, чтобы снизить риск атаки через цепочку поставок.
- **XSS в виджете невозможен:** виджет строит интерфейс только через `textContent`.

## Технологии

Python 3.11+, aiogram 3, aiohttp, SQLite (WAL), cryptography, pytest.
Telegram Bot API 10.4 (HTML-виджеты), MAX Bot API.

```
core/        логика записи (не зависит от мессенджера)
adapters/    telegram/ и max/ — тонкие адаптеры
widgets/     HTML-виджет календаря (≈1,9 КБ после сжатия при лимите 4 КБ)
tests/       22 теста: ядро, безопасность, сквозные сценарии Telegram и MAX
```

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp config.example.toml config.toml   # услуги, мастера, часы работы
cp .env.example .env                 # токены и ключи (инструкции внутри)
set -a && source .env && set +a
python run_telegram.py               # и/или python run_max.py
pytest                               # тесты
```

Круглосуточная работа на VPS: готовые службы systemd с песочницей (без root, только своя папка,
лимит памяти) и пошаговая инструкция — в [`deploy/`](deploy/README.md).
